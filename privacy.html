Privacy policy

Last updated: November 23, 2026

strata-drive is a desktop application that runs only on the user's own computer. It uses the Google Drive API, with the user's permission, to list, open, download, and upload the user's own Google Drive files, and to show Google-generated thumbnails.

What data is accessed

Google Drive file names, folders, metadata, thumbnails, and file contents, only as needed to carry out actions the user takes on their own computer.

Where data goes

Data travels only between the user's computer and Google. strata-drive has no server. No data is collected, stored, shared with, or sold to the developer or any third party. The sign-in token is stored only on the user's computer.

Use of Google user data

strata-drive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
